# User Stories

## Story 1
As a user, I want to create an account so I can access the parking system.

Acceptance Criteria:
- Email must be unique
- Password must be valid
- User is redirected to dashboard

## Story 2
As a user, I want to view parking availability so I can choose a free spot.

Acceptance Criteria:
- Map displays parking locations
- Spot colors represent status

## Story 3
As a user, I want to reserve a parking spot so I can secure my place.

Acceptance Criteria:
- Time selection is available
- Reservation is saved
- Spot status changes to reserved
