🅿️ Smart Parking System (OpenCV + Docker)

This project is an AI-powered smart parking system built with Computer Vision.
It analyzes live or recorded parking lot footage and automatically detects available parking spots.

🚀 How to Run

Clone the repository:

git clone https://github.com/supertankerlol/Parking-system.git
cd Parking-system


Install Docker and Docker Compose

Build and start the project:

docker-compose up --build


To mark parking areas (choose 4 points per spot):

docker-compose run smart-parking python editor.py

🧩 Technologies Used

OpenCV – for image processing and object detection

cvzone – for easy visualization overlays

NumPy – for pixel-level array operations

Docker – to containerize and deploy easily

Python 3.9 – the main programming language

⚙️ Features

✅ Detects free and occupied parking spots in real time
✅ Editable parking zones (draw 4-point polygons)
✅ Adjustable thresholds using interactive trackbars
✅ Works with both static images and video input
✅ Fully Dockerized — easy to run anywhere
